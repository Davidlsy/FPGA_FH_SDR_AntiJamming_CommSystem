# S5 viterbi_dec BER 三路同序列对比（Viterbi BER 对比图）

> **任务**: S5 #5 收口遗留项「Viterbi BER 对比图」——`docs/spec/s5_rx_interface.md` §4.4
> 验证判据的第二、三条（第一条「与浮点参考逐比特比对」已由位真套件覆盖）。
> **判据**（§4.4 原文）: BER 与 MATLAB `vitdec` 同序列叠图；**与浮点参考 BER 差 ≤0.5 dB、
> 高 SNR 无误码平底**。
> **日期**: 2026-10-09
> **入口**: `sim/golden_ref/run_viterbi_ber.py`（产物 `data/s5_viterbi_ber/`）

## 1. 对比口径（三路同序列）

三路译码器拿到**同一条**量化后软序列——即 RTL `viterbi_dec` 输入口的真实序列：

| 路 | 实现 | 语义 |
|---|---|---|
| 浮点参考 | `golden_ref.float_chain.viterbi.viterbi_decode` | float PM + 全回溯（归零帧，块最优） |
| 硬件忠实 | `golden_ref.fixed_point.rx_modules.fixed_viterbi_hw` | Q3.5 整数 PM + 16 bit 饱和 + 每步归一化 + **滑窗 96**（= RTL 语义，位真裁判） |
| MATLAB 交叉 | `vitdec(soft, poly2trellis(7,[171 133]), 96, 'trunc', 'unquant')` | 滑窗截断模式 + 软输入实数（正 = 更可能为 0），与 RTL 同为滑窗截断 |

- **帧结构 = 链路真帧**：2160 信息比特 + 6 尾比特（归零）→ `conv_encode` → 4332 编码比特/帧；
- **软值模型**：`z = 1 − 2·bit`（bit0 → 正，与 `sync_rx` 软解调同向）+ 高斯噪声，
  `σ² = N0/2 = 1/γb`（γb = Eb/N0；Ec = 1/编码比特、R = 1/2 → Eb = 2），再 **Q3.5 格点化
  round(soft·32)/32 + ±127/32 饱和**（`viterbi_metric_w=8 / frac=5`，模块输入格式）；
- **同序列的含义**：噪声实现逐帧一致、量化后软值逐个一致，三路差异**只来自译码器实现**
  （PM 精度、归一化、回溯模式）；配对比较（同一帧两路对错分歧计数）比独立曲线灵敏得多；
- **交织与脉冲成形不在此级**：交织是 i.i.d. 信道下的比特置换，不改 BER；链路级效应
  （SRRC、同步、软解调量化密度）由 S1 基线（`data/s1_ber_baseline/`）覆盖；
- **绝对 Eb/N0 口径**取教科书卷积码约定（R = 1/2 BPSK 逐编码比特），曲线瀑布点应落在
  BER 1e-5 ≈ 4.3~4.6 dB，与设计报告「编码 1e-5 约 4.6 dB」锚点互证（见 §3 交叉核对）。

**MATLAB 模式为何取 `'trunc'` 而非 `'term'`**：帧虽归零终止，但 RTL 是**滑窗 96 判决**
（`TB_DEPTH=96` 直移回溯），不是块最优译码；`'term'` 会把终止状态知识给 MATLAB，比对的是
"模式差"而不是"实现差"。取 `tblen=96` 的 `'trunc'` 使三路回溯语义同构，叠图差异可归因。

## 2. 方法与规模

- **扫点**: Eb/N0 = 0, 1, 2, 3, 3.5, 4, 4.5, 5, 5.5, 6 dB（10 点）；
- **自适应停点**: 每点 `min(误码_float, 误码_fixed) ≥ 50` 或 6×10⁵ bit 或 400 帧（2160 bit/帧）；
- **种子**: 主种子 20261009，逐点派生 `seed + 1000·idx`，全程可复现；
- **统计**: 逐点记录两路误码、**配对分歧**（只有一路错的比特数）、MATLAB 路误码；
  零误码点给 95% 置信上界 3/N 参与平底观察；
- **判据判法**:
  1. *≤0.5 dB*：对 fixed / float 两条曲线在目标 BER（1e-2…1e-5）处对数域插值求
     Eb/N0 差，取可达目标的最大值（沿用 S1 `snr_loss_analysis` 同一裁判函数）；
  2. *无平底*：最高 3 点的 fixed BER 不得回升，且 fixed/float 误码比不得在相邻两点持续 >3。

## 3. 结果

**判定：PASS**——三条判据（≤0.5 dB 损失、与 MATLAB 同序列叠图、高 SNR 无平底）全过。
入口 `python run_viterbi_ber.py`（全量），产物 `data/s5_viterbi_ber/`
（`ber_curve_viterbi.png` 三线叠图 / `snr_loss_table_viterbi.csv` / `ber_viterbi.npz`）。

### 3.2 判据一：与浮点参考 BER 差 ≤0.5 dB

对数域插值（沿用 S1 `snr_loss_analysis` 裁判函数）：

| 目标 BER | SNR 损失 (dB) | 判定 |
|---|---|---|
| 1e-2 | 0.004 | 通过 |
| 5e-3 … 1e-4（五档） | 0.000 | 通过 |
| 1e-5 | −0.061 | 通过 |
| **最大可达损失** | **0.004** | **≤ 0.5 dB，通过** |

1e-5 处的 −0.061 dB 不是"硬件比浮点好"：该点已贴到零误码悬崖（4.0 dB float 0 错、fixed 2 错），
插值落在统计涨落里；按绝对值并入最大值仍是 0.004 dB，远低于门槛。

### 3.3 判据三：高 SNR 无误码平底

5.0 / 5.5 / 6.0 dB 三点 fixed 与 float **均零误码**，95% 上界 3/N = 7.47e-6 随 N 持平——
这是"零误码 + 统计上界"的签名；平底的签名（BER 停在 ~1e-4 量级不再下降、fixed/float 比值
相邻点持续 >3）**均未出现**，判定 **无平底**。

### 3.4 判据二：与 MATLAB `vitdec` 同序列叠图 + 配对分歧

三路合计 2.48 Mbit 同一条软序列。逐点看：

- **MATLAB 与 fixed 路几乎逐点重合**：2/3/3.5/4/4.5/5/5.5/6 dB 逐点误码数完全相同，
  仅 0 dB 差 1 bit（434 vs 433）——两路同为滑窗截断回溯，叠图差异在绘图线宽以内；
- **float（全回溯）与两路的分歧集中在低 SNR**：0 dB 22/25、1 dB 3/7（只有一路错的比特数）；
  ≥2 dB 除 4.0 dB 临界点（fixed 与 MATLAB 同错 2 bit、float 0）外**逐比特全同**；
- **分歧归因**：滑窗 96 在窗口边界提前判决 vs 全回溯的块最优判决——低 SNR 时幸存路径
  出现长距离错误事件，窗口边界处两语义必有少量分歧；这是**回溯模式的固有差异**，不是实现
  缺陷（`fixed_viterbi_hw` 与 RTL 的逐比特一致性已由位真套件 `run_viterbi_dec_check.bat`
  三用例 0 错误锁定）。4.0 dB 临界点的 2 bit 分歧（fixed 与 MATLAB 同错、float 全对）在
  量级上与单次窗口边界错误事件相符。

### 3.5 与链路锚点互证

瀑布点（BER 1e-5）落在 **≈4.4 dB**（3.5→4.5 dB 之间），与设计报告理论锚点
「编码曲线 1e-5 约 4.6 dB」（`docs/report/s1_archive_compare.md` 转引）同段吻合；
本次三路同序列口径下两路滑窗实现贴着浮点全回溯走，无额外实现损耗，锚点互证成立。
