# 引脚映射表（AX7Z020B）

> 与 `board/fhss_zynq_pins.xdc` **1:1 对应**；改动必须同步两侧并走评审。  
> 对应交付节点：P0′-S1（占位表）→ P1′-S1（板到货后按原理图冻结）→ BV-02 复核  
> 编制依据：ALINX AX7Z020B 用户手册 sec 2.5 / 用户 LED 章节（核对日期 2026-09-16）

## 1. 文件配对与维护规则

| 文件 | 职责 | 跨板策略 |
|------|------|----------|
| `src/constraints/fhss_zynq_timing.xdc` | 时钟 / 时序例外 / 配置属性 | 跨板复用，**换板不改** |
| `board/fhss_zynq_pins.xdc` | PACKAGE_PIN / IOSTANDARD / SLEW / DRIVE | **每板一份**，换板只替换此文件 |
| `docs/pins.md`（本文件） | 人读引脚表、来源、状态、评审记录 | 与本板 pins.xdc 同步维护 |

维护规则：

1. **本表与 `fhss_zynq_pins.xdc` 保持 1:1**：每一条已使能的 `set_property` 在此有对应行；每一行状态为「已填」的引脚在 xdc 中不得被注释掉。
2. xdc 只写物理属性；时钟周期、`set_input_delay`、`set_clock_groups` 等一律写在 timing 文件。
3. 引脚号变更 = 评审事件：更新本表 + xdc 同一次提交，并在文末「变更记录」留痕。
4. 板卡更换（含 D0 兜底换板）时：新建 `board/<board_id>/` 下对应 xdc，并在 `docs/` 旁路维护该板 `pins.md`；timing 文件不动。
5. **状态 `待填` 的行禁止下载到实体板**——当前 bitstream 仅用于工具流验证（综合→实现→bit）。

## 2. 板卡身份

| 项目 | 值 |
|------|-----|
| 目标板 | ALINX **AX7Z020B** |
| FPGA | XC7Z020-CLG400-2（Zynq-7000） |
| 扩展口 | 2 路 40 针 2.54 mm PL 排针（AD9363 模块互连载体） |
| PL 侧默认电平 | BANK34/35 VCCO = 3.3 V → LVCMOS33 |

**板龄差异警告**：2016 年前后 ALINX AX7020 的用户 LED 封装脚为 M14/M15/K16/J16，与本表（AX7Z020B 手册）的 J14/K14/J18/H18 **不一致**。板卡到货当天必须对照实物丝印 / 原理图复核本表与时钟脚；复核完成前，bitstream 仅供流程验证，不得作为板级结论。

## 5. IO 标准与降额策略（写入 xdc 的统一口径）

| 信号类 | IOSTANDARD | SLEW | DRIVE | 理由 |
|--------|------------|------|-------|------|
| 板载晶振 `sys_clk` | LVCMOS33 | 默认 | 默认 | 单端时钟，手册指定 |
| 用户 LED | LVCMOS33 | 默认 | 默认 | 低速指示，无 SI 问题 |
| AD9363 数据 / 时钟 / SPI 输出 | LVCMOS33 | **SLOW** | **4** | 牺牲边沿换排针反射裕量 |
| AD9363 MISO / 按键（输入） | LVCMOS33 | — | — | 输入不设 SLEW/DRIVE |
| 配置 bank（CFGBVS / CONFIG_VOLTAGE） | — | — | — | 见 timing 文件 `[6]`：VCCO / 3.3 V |

SI 预算（BV-02 判定闸相关）：

- 排线长度 < 10 cm，地针交错，40 针中约 1/3 接地  
- CMOS 模式硬件上限 61.44 MSPS，工程降额起点 **20 MSPS**（1 Mbps 链路裕量充足）  
- 判定闸：数字环回误码 **≤ 1e-7**；不达标则逐级降采样率（20→10→5 MSPS）找稳定点；仍不过 → 触发 **D0** 转 Pluto 兜底  

## 6. 与时序约束的接口

| 时钟域 | 物理来源 | 约束位置 | 本表对应脚 |
|--------|----------|----------|------------|
| A 基带 | 板载 50 MHz（U18）→ MMCM ~61.44 MHz | timing `[1]` + MMCM 派生 | §3.1 `sys_clk` |
| B 控制面 | PS FCLK_CLK0 100 MHz | timing `[2]`（PS7 自动） | 不在 PL 引脚表 |
| C 射频采样 | AD9363 DATA_CLK = 采样率 | timing `[3]` | §4.1 `ad9363_data_clk` |
| D SPI 伪域 | FCLK 分频 ≤ 20 MHz | timing `[4]`（false_path） | §4.2 SPI 脚 |

PS GEM 125 MHz 在 PS/MIO 域，**不进**本引脚表，也不进 timing 文件（PHY 挂 MIO，RGMII 时序由 PS7 配置保证）。
