为什么接收链接口必须先于 RTL 冻结：四个模块是**逆着发射链**走的单方向串联，而发射链的长度与位宽
已被 `s4_tx_interface.md` §2/§3 锁死（2160 → 2166 → 2170 符号 → 8712 采样）。接收侧只要有一处
抽取比、取样相位或位序与发射侧**不成逆**，S8 全链环回就会整段红，而且症状是"BER 高得离谱"，
极难定位到具体是哪一级。所以本规格先把"逆映射的每一级长度/位宽/节拍"写死，再写 RTL。

## 1. 通用流控约定（沿用 `s4_tx_interface.md` §1，接收侧适用）

1. **valid-only，无背压**：只有 `din_valid/din_data` 与 `dout_valid/dout_data`，**没有 `ready`**。
   上游一拍能出一拍，下游必须能收下。
2. **按 valid 对齐，不按绝对时刻对齐**：允许各级流水延迟不同（CIC 与匹配 FIR 的延迟本就不一样），
   比对只认各自的 valid。
3. **复位语义**：同步低有效复位。复位后各级回到空闲：CIC 积分器 / 梳状器归零，Costas 相位累加器
   与早迟门定时 NCO 归零，交织存储器写指针归零，Viterbi 路径度量初始化为「仅状态 0 度量为 0、
   其余为饱和最大值」。
4. **比特序 MSB-first**：软判决比特与译码输出同为高位在前；总线打包"高位在前"，例如 `{i, q}`
   表示 I 在高位段。
5. **判据行必须纯 ASCII**（脚本只 match ASCII 字段，见 `sim/README.md` §5）。
6. **多速率显式化（接收链特有）**：接收链是**多速率**（ADC 采样率 → 4 sps → 1 sps → 比特域）。
   每一级的输入/输出速率关系必须显式写在 §3，**不得靠"valid 稀疏"隐式表达**——隐式多速率是
   接收链最容易产生"数字对不上"的一类错，而这类错在位真比对里表现为整体错位，最难回溯。

## 2. 模块接口总表

| 模块 | 输入 | 输出 | 速率 / 拍数关系 | 本版状态 |
|---|---|---|---|---|
| `ddc_rx` | ADC 复采样 `{i,q}`（2×12 bit） | 4 sps 复采样（2×14 bit） | **D : 1**（D = f_adc / 2 MSPS，参数） | 冻结 |
| `sync_rx` | 4 sps 复采样 | 1 sps 判决符号 + 软判决比特 | **4 : 1**（早迟门定取样相位） | 冻结 |
| `blk_deinter` | 软符号 `{i_soft[7:0],q_soft[7:0]}`（16 bit/拍） | 同宽（16 bit） | **2170 → 2166**（4340 → 4332 软值，去 8 bit 补零） | 冻结（另立，S5 内可旁路） |
| `viterbi_dec` | 软符号 `{i_soft[7:0],q_soft[7:0]}`（8 bit/5 小数） | 译码信息比特 | **2N → N − 6**（N = 编码符号数） | 冻结 |

接收链与发射链的**逆映射关系**（本规格的核心约定）：

```
发射（已冻结）  frame_tx → conv_enc → blk_inter → qpsk_map → srrc_duc
                256B→2160b  2160→2166   2166→2170     1:1      2170符号→8712采样
接收（本规格）  ddc_rx ─→ sync_rx ─→ [软解调] ─→ blk_deinter ─→ viterbi_dec
                →8712采样@4sps  →2170符号   →4340软比特   →4332比特    →2160信息比特
```

`sync_rx` 输出判决符号、并在**输出端**生成软判决比特（每符号 I/Q 各 1 软比特）。四段之间
**不需要任何串并转换**：一拍一个复采样、一拍一个符号，粒度天然对齐；这条不冻结，后面一定会有人
在中间塞一个 serializer，然后逐拍比对全线错位。

> `blk_deinter` 是对任务卡"3 模块"的**范围补充**（计划书只列 `ddc_rx`/`sync_rx`/`viterbi_dec`）：
> 接收链是发射链的逆，而发射链里交织夹在编码与映射之间——**没有解交织器，S8 全链环回必断在此处**，
> 且 S5"三模块全过"会掩盖该断点。登记为 §7 有意偏差 #3。

## 3. 拍数账本（从采样到译码比特，逐模块）

按**一帧**计（连续流的帧界由帧同步划定，属 S6；本规格只保证单帧长度关系确定）：

| 环节 | 输入 | 输出 | 说明 |
|---|---|---|---|
| `ddc_rx` | `D × 8712` 采样 @ f_adc | **8712 采样 @ 4 sps** | 抽取到 4 sps（= 2 MSPS），与发射侧 8712 采样一一对应 |
| `sync_rx` | 8712 采样 @ 4 sps | **2170 判决符号** | 4:1 取样（早迟门定相位），恢复 2170 符号 |
| 软解调（挂 `sync_rx` 输出端） | 2170 符号 | **4340 软比特** | 每符号 I/Q 各 1 软比特，先 I 后 Q |
| `blk_deinter` | 2170 拍 × 2 软值（4340 软比特） | **2166 拍 × 2 软值（4332）** | 逆 `blk_inter` 置换 + 去 8 bit 补零 |
| `viterbi_dec` | 4332 比特 = 2166 对 | **2160 信息比特** | 逆 `conv_enc`，去 6 尾比特 |

**接收取样窗口（本版冻结）**：发射侧输出是 `4N + 32`（full 卷积拖尾，见 `s4_tx_interface.md` §6.1），
接收侧稳态符号只有 `4N` 对应的 2170 符号。约定：

- 发射的 32 拍拖尾由**接收匹配滤波窗口吸收**（落在匹配滤波群延迟边缘，不参与判决）；
- 判决窗口**起点不靠猜**——以**已知前导**在接收侧的检测点对齐，偏移 = 定时锁定点 + 匹配滤波群延迟补偿；
  该偏移在 #16 位真比对时以「与发射符号逐个同相」为唯一判据实测锁定，**写入向量 `meta.json`**
  （与 S4 向量落 `stim_period` 同一纪律）。

## 4. 各模块接口详述

### 4.1 ddc_rx

```verilog
module ddc_rx #(
    parameter int DECIM_RATIO = 4,     // 抽取比 D = f_adc / 2 MSPS；S5 验证档位 D = 4（f_adc = 8 MSPS）
    parameter bit USE_CIC_IP  = 1'b0   // 1 = CIC Compiler IP 版；0 = 手写 RTL 版
) (
    input  logic        clk,
    input  logic        rst_n,
    input  logic        din_valid,
    input  logic [23:0] din_data,      // ADC 复采样 {i[11:0], q[11:0]}（AD9363 原生 12 bit）
    output logic        dout_valid,
    output logic [27:0] dout_data      // 4 sps 复采样 {i[13:0], q[13:0]}（Q3.11）
);
```

- **抽取比是参数，不在 P0 焊死**：`f_adc` 由 AD9363 配置决定（板级，BV-01，板卡未到货）。
  冻结的是**速率关系**（输出固定 4 sps）与**参数形式**；S5 验证档位取 **D = 4**——
  整数、够小、且 `D > 1` 才真压到 CIC 通路（D=1 等于旁路，60 dB 动态与溢出用例就白测）。
  换档位只改激励长度与 CIC 参数，**不改下游、不影响位真比对**。
- **结构（两段串接）**：先 **CIC 抽取**（CIC Compiler IP 或手写 RTL，双轨），把 f_adc 降到 4 sps；
  再 **匹配 FIR**（与发射端 SRRC **同源**的 33 抽头、12 bit 量化系数），在 4 sps 上做脉冲成形匹配。
  顺序不可颠倒：先降到符号率的 4 倍，再做匹配滤波，才能与发射侧 `srrc_duc` 的 ×4 多相严格成逆。
- **48 bit 累加改 DSP48E1 级联**（任务卡指定）：CIC 积分器位宽宽，须把累加拆成 DSP48E1 级联；
  **流水级对齐是关键**——级联每一级的 P 寄存器要显式打拍，否则组合路径过长、时序不收敛
  （S4 的 `srrc_duc` 手写版就是被组合 MAC 路径拖到 Fmax 33.79 MHz，见 README 已知边界）。
- **CIC 分档（P1 实现时确定，已登录 `config.RX_CONFIG`）**：级数 **N = 3**、微分延迟 **M = 1**、
  抽取比 **D = 4**（验证档位）→ 增益 `(D·M)^N = 64 = 2⁶`，输出**右移 6 位**（round half-to-even）
  还原单位增益。结构 = N 级积分器（输入速率）→ 抽取 D → N 级梳状器（输出速率）；
  累加器按 48 bit **模 2⁴⁸补码卷绕**（正常量级不触发）。
  实测（`sim/golden_ref/sim/check_rx.py`）：通带增益 0.998@0.02 → 0.875@0.169，
  **带边 droop ≈ −1.2 dB**（CIC 固有一阶下垂，由接收匹配滤波一并考虑）；带内 −60 dB 音输出
  峰值 ≈ 1 LSB，动态范围可分辨。级数 3 与 S1 预留的 `cic_stage_w`（3 项）对齐，
  但**累加器位宽以任务卡的 48 bit 为准**（见 §7 #5）。
- **双轨纪律**（同 S4）：IP 版与手写版**共用同一套向量、同一套 TB**，位真结果必须一致。
- **输入速率约束**：无背压约定下，上游平均速率必须满足 §3 的额定关系；TB 按 §3 生成激励。
- **验证判据**：DDC 通带与发送 SRRC 匹配；**60 dB 动态范围仿真无溢出**（含饱和与抽取相位边界用例）。

### 4.2 sync_rx

```verilog
module sync_rx (
    input  logic        clk,
    input  logic        rst_n,
    input  logic        din_valid,
    input  logic [27:0] din_data,      // 4 sps 复采样
    output logic        dout_valid,
    output logic [27:0] dout_data,     // 1 sps 判决符号（Q3.11）
    output logic [7:0]  dout_soft_i,   // I 路软判决（8 bit / 5 小数）
    output logic [7:0]  dout_soft_q,   // Q 路软判决（8 bit / 5 小数）
    output logic [15:0] phase_err,     // 载波环路可观测（收敛报告用）
    output logic [15:0] timing_err     // 定时环路可观测（收敛报告用）
);
```

- **载波恢复：二阶 Costas 环**（相位 + 频偏），直移实现（不查表），更新率 **1/符号**；
- **定时恢复：早迟门（early-late gate）直移**，更新率 **1/符号**；取样相位与发射侧多相相位成逆
  （发射侧相位 0 有 9 抽头，见 `s4_tx_interface.md` §6.1）；
- **早迟门误差极性（本版冻结）**：`te = |late|² − |early|²`，`te > 0` = 采样偏早（迟端能量大）→
  `mu` 该增大，故 `mu += Kp·te` 为**负反馈**；极性反了是正反馈且载波残差判据察觉不到（§6 第 6 条）；
- **环路参数数值已冻结**（2026-10-09 任务 #3 标定；原决策 2 悬置项收口）：Q1.19 系数
  `costas_kp/ki = 2336/64`、`timing_kp/ki = 1835/104`，增量语义 `inc = round_he(err × coef, 14)`；
  **数值单一来源 `config.RX_CONFIG`**，规格载体 `fixed_point_spec.md` v1.1 §3.4（含等效浮点换算与
  标定教训）。本规格只冻结结构、位宽与语义，不复刻数值；
- **环路可观测（本版冻结：引出）**：`phase_err` / `timing_err` 由收敛报告消费；
- **损伤注入（TB）**：±1 kHz 频偏 / 随机相偏 / ±20 ppm 符号率偏差（计划书指定）；
- **验证判据（两种口径，勿混用）**：
  ①**解调对错**：±1 kHz 频偏下 **≤500 符号收敛**，收敛窗口前的符号只用于收敛曲线、不入判据；
  ②**位真比对**（RTL vs golden）：**自第 1 个符号起**（两者共享复位状态、暂态逐符号确定，
  `SKIP_OUT = 0`），不需要收敛窗口——否则暂态里的实现分歧会被窗口掩盖（§6 第 3 条）。

### 4.3 blk_deinter

```verilog
module blk_deinter #(
    parameter int DEPTH = 10,      // 交织深度，与 blk_inter 相同（不另设）
    parameter int N_COL = 434      // 列数 = ceil(4332 / DEPTH)，与 blk_inter 相同
) (
    input  logic        clk,
    input  logic        rst_n,
    input  logic        din_valid,
    input  logic [15:0] din_data,     // 一个"软符号"：{i_soft[7:0], q_soft[7:0]}（8bit/5 小数）
    output logic        dout_valid,
    output logic [15:0] dout_data
);
```

> **位宽口径（本版澄清，原稿 §4.3 写成 `[1:0]` 与 §2/§3 自相矛盾）**：本模块搬的是**软判决值**
> （8 bit/5 小数），不是一个符号的 2 个硬比特。故总线 **16 bit**（一拍两个软值、高位在前），
> 拍数是 **2170 → 2166**（不是 4340 → 4332 比特）。之所以同一个置换对"4340 个比特"和
> "4340 个软值"都成立，是因为发射侧也是**一拍一个 2 bit 字**（`blk_inter` 的 2bit/符号），
> 两侧的元素序完全一致——这也正是 {I,Q} 打包顺序必须全程一致的原因。

- **逆 `blk_inter`**：发射侧"写行优先、读列优先"，本模块**写列优先、读行优先**，严格互逆；
- **几何参数共用**：`DEPTH=10`、`N_COL=434` 必须与 `blk_inter` 取同一值，**不得另设**——
  两处几何不一致 = 位序整体错，且症状是"译码全错"而非"少一位"，最难查；
- **去补零**：发射侧补的 8 bit（padded 序末 4 个字）在逆变换时丢弃 → 输出 4332 个软值（2166 拍）；
- **位真裁判**：`float_chain/interleaver.py` 已有 `block_deinterleave`，经实测是 `block_interleave` 的
  **真逆**（含尾部 8 bit 补零）。但 `block_interleave` 内部用 `np.zeros(..., dtype=np.int8)` 建缓冲，
  **不能承载软值**（会把 float 强转 int8 而毁数据）。故 P1 在 `fixed_point/rx_modules.py` 增补
  dtype 无关的 `soft_interleave` / `soft_deinterleave`（同一置换、任意 dtype 可用；
  `soft_deinterleave(x, depth, n_out=4332)` 直接给出"去补零"结果）；
- **归属**：**另立模块**（不塞进 `viterbi_dec`，避免译码器职责不纯、位真裁判难切分）；
  S5 内可先旁路开关，独立成一套件做位真比对。

### 4.4 viterbi_dec

```verilog
module viterbi_dec #(
    parameter int TB_DEPTH = 96         // 回溯深度（任务卡指定）
) (
    input  logic        clk,
    input  logic        rst_n,
    input  logic        din_valid,
    input  logic [15:0] din_soft,      // 每符号 2 软比特 {i_soft[7:0], q_soft[7:0]}（8 bit/5 小数）
    output logic        dout_valid,
    output logic        dout_bit       // 译码信息比特，MSB-first
);
```

- **64 状态 ACS**（K=7 → 2^(K−1) = 64，与 `config.py` 的 `CONV_K=7` 一致）；
- **软判决度量位宽 = 8 bit / 5 小数**（继承 S1 `viterbi_metric_w/frac`）；**不采用任务卡"5 bit"**
  （见 §7 #1；"5"指小数位）；
- **分支度量 = 绝对值型**（与 `float_chain/viterbi.py`、`fixed_viterbi_decode` 的 `abs` 模式一致）；
- **路径度量 16 bit / 5 小数 + 每步归一化（减全局最小值）**，防止累积溢出；
  **归一化做法必须与浮点参考同构**（§6 第 4 条）——否则低 SNR 下回溯分歧；
- **回溯单元**：深度 **96** 直移，回溯存储 **BRAM36 × 8**（任务卡预算）；
  实测存储需求 ≈ `96 × 64 × 1 = 6.1 kbit`，8 块 = 288 kbit，**余量约 47 倍**——
  预算宽松，故不因"怕超 BRAM"而妥协位宽；实际块数以 #10 综合结果为准；
- **自研是既定决策**：AMD 无免费软判决 Viterbi IP，故自研；此点不构成"为何不用 IP"的疑问；
- **验证判据**：与浮点参考 `viterbi_decode` 逐比特比对；BER 与 MATLAB `vitdec` 同序列叠图；
  **与浮点参考 BER 差 ≤0.5 dB、高 SNR 无误码平底**。

## 5. 同步环语义与 S6 跳频预留

S4 在 §5.2 冻结了发射侧 NCO 的"相位连续"语义以便 S6 直接换字。接收侧的对应物是**同步环路状态**——
跳频时中心频点每跳变化，接收侧必须明确环路如何应对。本节只记语义（S6 实现）：

1. **载波环**：跳频使载波频偏每跳突变，Costas 环是「每跳重新捕获」还是「保持并牵引」，待 S6 冻结；
   本规格只要求接口预留可重置 / 可保持两种语义。
2. **定时环**：跳频不改变符号率（除非 S6 改速率），早迟门定时 NCO **保持不清零**。
3. **接口预留**：接收侧需能接收「跳沿」指示以决定环路动作；本规格不实现，仅登记该预留点。

## 6. 存储与仿真口径（踩过的坑，本规格强制）

1. **BRAM 上电内容为 X**：回溯存储器与交织存储器必须"先写满再读"，或在 TB 里显式初始化，
   否则读到未写区域会把 X 带进比对器，产生假失败。
2. **多速率激励**：接收链是 4 sps → 1 sps，TB 必须按 §3 的速率生成激励；
   沿用 `tb_vec_cmp` 已有的 `STIM_PERIOD` 能力（S4-P0 已落地并自测）。
3. **环路收敛窗口属"解调对错"判据，不是位真比对的口径**：损伤注入用例判"解调对错"要给 ≥500 符号
   的收敛窗口（锁定前的符号只画收敛曲线、不入判据，否则"未锁定"会被算成"数据错"）；但
   **RTL vs golden 位真比对自第 1 个符号起**（两者共享复位状态、暂态逐符号确定，`SKIP_OUT = 0`）。
   两种口径混用会两头翻车：要么暂态被误判成数据错，要么暂态里的实现分歧被收敛窗口掩盖。
4. **定点 PM 归一化必须与浮点参考同构**：每步减**全局最小值**以保 16 bit 不溢出；
   若 RTL 用"减状态 0 度量"而参考用"减全局最小值"，PM 数值会漂移，导致回溯分歧
   （症状：高 SNR 通过、低 SNR 失败）。
5. **BRAM36 面积预算宽松**：回溯存储 8 块是任务卡预算（实测需求 ≈6.1 kbit，余量约 47 倍）。
   若回溯深度或软判决位宽调整，仍须复核块数，但**不必为省 BRAM 而做位宽妥协**。
6. **同步环两条标定教训**（改系数前必读，全文见 `fixed_point_spec.md` §3.4）：
   ①早迟门误差极性必须是 `|late|² − |early|²`——反了是正反馈，mu 在 ±2 采样间乱跳、采样点滑出
   符号峰，而**载波残差判据照样过检**，故收敛判据必须含定时项（mu 尾段界）；
   ②积分增益 Ki 必须高于整数乘积 `(err×Ki, 14)` 的量化死区，否则积分路径恒不走——定时环误差 ∝ A²，
   半幅度下最明显（Ki_t=13 时 mu 卡死不跟 500 ppm 漂移，Ki_t=104 才跟住）。

### 6.1 接收链位宽与架构（P0 冻结，2026-10-08）

位宽账本（单一来源 `fixed_point_spec.md` + 任务卡）：

| 环节 | 位宽 | 小数 | 来源 / 状态 |
|---|---|---|---|
| `ddc_rx` 输入（ADC 复采样） | 2 × 12 | — | AD9363 原生 12 bit（板级接口，§7 #4） |
| CIC 累加器 | 48 | — | 任务卡指定（**取代 S1 预留的 `cic_stage_w`**，见 §7 #5）；N=3 / M=1 / D=4，增益 2⁶ |
| `ddc_rx` / 匹配 FIR 输出 | 14 | 11 | 继承 S1 `awgn_out_w / out_frac` |
| `sync_rx` 判决符号 | 14 | 11 | 继承 S1 `sync_out_w / out_frac` |
| 软判决度量（Viterbi 输入） | 8 | 5 | 继承 S1 `viterbi_metric_w / metric_frac`（§7 #1） |
| Viterbi 路径度量 | 16 | 5 | 继承 S1 `viterbi_pm_w / pm_frac` |
| Viterbi 回溯存储器 | — | — | BRAM36 × 8（任务卡预算，余量约 47×） |

三条位真一致硬口径（**本版冻结**）：

- **匹配 FIR 系数必须与发射侧同源**——同一份 12 bit 量化系数，否则"S1 之后不再有第二套真理"
  被破坏（`s4_tx_interface.md` §7 第 1 条的同一纪律）；
- **早迟门取样相位与发射多相相位成逆**——发射侧多相相位 0 有 9 抽头，接收侧取样窗口必须对应；
- **位序**：软判决比特先 I 后 Q，与发射侧 `qpsk_map` 的 `{i_bit, q_bit}` 及 `{i_out, q_out}` 一致。

## 7. 与任务卡 / 计划书的有意偏差（登记，不隐藏）

以下 4 条已于 **2026-10-08 P0 评审确认**（见 §8 冻结记录）：

| # | 任务卡 / 计划书写法 | 本规格做法 | 理由 |
|---|---|---|---|
| 1 | viterbi「5 bit 软判决」 | S1 冻结 `viterbi_metric_w = 8`（3 整数 + 5 小数） | 位真裁判必须同源；"5"指小数位。改 5 bit 会劣化软判决增益、与「BER 差 ≤0.5 dB」冲突，且须重跑 S1 BER |
| 2 | 计划书 S6「同步字捕获：32 bit Gold 滑动相关」 | `frame_format.md` 冻结同步字为 **64 bit**（Gold 周期 63 + 首位重复） | 两处口径不一致；已统一为 64 bit，"32 bit"移交 S6 更正 |
| 3 | 计划书接收链列 **3 模块** | 逆链还需**解交织器 `blk_deinter`**（逆 `blk_inter`） | 无它则 S8 全链断在解交织，且 S5"三模块全过"会掩盖该断点；故另立第 4 个模块 |
| 4 | — | `ddc_rx` 输入位宽按 AD9363 12 bit 记 | 板级未定，先按器件原生位宽登记；物理接口截断点属板级（BV-03），仿真域结论不引用 |
| 5 | S1 定点规格预留 `cic_stage_w = [16, 18, 20]`（3 级 × 11 小数） | CIC 累加器取 **48 bit**（任务卡「48bit 累加」），级数 **N = 3**、M = 1 | 两者冲突；48 bit 是 DSP48E1 原生宽度，按任务卡取。S1 的 `cic_stage_w` 预留**即被取代**，属 S1 定点规格变更（走 `fixed_point_spec.md` §5，须重跑 BER 基线）——**待评审确认** |
| 6 | 计划书未给 DDC 的 CIC 级数/微分延迟 | 由黄金模型定为 **N = 3、M = 1、D = 4**（增益 2⁶，右移 6 位归一） | 计划书只说「CIC 抽取」，参数空缺；以「与 S1 预留 3 项对齐 + 增益为 2 的幂」为准则定，见 §4.1 |

## 8. P0 冻结记录（2026-10-08，原"待冻结清单"八项已定）

| 项 | 冻结值 |
|---|---|
| DDC 输出速率 | **4 sps = 2 MSPS**（与发射 `srrc_duc` ×4 严格对称，是其逆） |

## 9. 变更流程

1. 提交变更申请：说明改哪个模块的哪条约定、影响哪些下游与哪些向量；
2. 改 `docs/spec/s5_rx_interface.md`（与 `s4_tx_interface.md` 同规）；
3. 重跑 `sim/framework/run_selftest.ps1`（框架契约本身是否仍成立）；
4. 重新导出全部 S5 向量并重跑 `sim/run_s5_acceptance.ps1`（**待建**，见 S5 任务清单）；
5. 若触及接收链位宽 → 按 `fixed_point_spec.md` §5 走定点规格变更，**并重跑 S1 BER 基线**
   （确认定点链相对浮点的 SNR 损失仍 ≤ 0.5 dB）；
6. 评审通过后更新版本号与冻结日期。
