## 0. 前置：`golden_ref` 接收侧三处缺口（P0 必须先补）

> 与 S4-P3 草稿 §0 同性质：位真裁判不到位，以下四项决策即便冻结也无从验证。

位真比对的裁判目前**到发射侧 DUC 为止**，接收侧三段的黄金模型都不满足 S5 要求：

| 缺口 | 现状 | 差距 | 需补 |
|---|---|---|---|
| `ddc_rx` | `sim/golden_ref/fixed_point/` **无任何 DDC/CIC 模型** | 完全没有 | 定点 CIC 抽取 + 匹配 FIR 模型（与发射 SRRC 同源系数） |
| `sync_rx` | `fixed_sync_receive` 只做「理想同步 + 4 次幂粗相偏」，且 `ideal=True` 时不做任何校正 | **不是**二阶 Costas + 早迟门；无频偏跟踪、无定时恢复 | 定点二阶 Costas + 早迟门模型 |
| `viterbi_dec` | `fixed_viterbi_decode` 用 float 累加，PM 不归一化、无回溯深度建模 | **非硬件忠实**；与 RTL 的 16 bit PM / 回溯 96 不可比 | 硬件忠实的定点 Viterbi 模型（16 bit PM + 每步归一化 + 回溯深度 96） |

三件套是决策 1/3 的裁判，**没有它位真比对无从谈起**，故列为 P0 的 0 号任务（= 任务 #17）。
`fixed_matched_filter` / `fixed_qpsk_demodulate_soft` / `fixed_add_awgn` 已存在，可直接复用。

## 决策 1：接收链速率与抽取口径

### 1.1 决策值

| 项 | 取值 |
|---|---|
| DDC 输出速率 | **4 sps = 2 MSPS**（与发射侧 `srrc_duc` 的 ×4 严格对称，是其逆） |
| DDC 输入速率 `f_adc` | **参数化**，不在 P0 焊死；S5 仿真**验证档位取 8 MSPS** |
| 抽取比 `D = f_adc / 2 MSPS` | **模块参数 `DECIM_RATIO`**，验证档位 **D = 4** |
| 符号率 `Rs` | **500 ksps**（= 2 MSPS / 4，继承 `s4_tx_interface.md` §8 冻结值） |
| 拍数关系 | 接收 **采样 : 符号 = 4 : 1**（发射 1 : 4 的逆） |
| RTL 时钟抽象 | 沿用 **「采样节拍」**（每 `clk` 沿 = 1 采样；与 S4 §8 同款抽象） |
| 接收取样窗口 | 发射 `4N+32` 拖尾由**接收匹配滤波窗口吸收**；判决输出取稳态 **2170 符号** |

### 1.2 为什么抽取比参数化而非焊死

`f_adc` 由 **AD9363 配置**决定，属板级事项（BV-01），当前未定（板卡未到货，见 README 已知边界）。
P0 能冻结的是**接口与速率关系**（DDC 输出 4 sps、抽取比是参数、时钟抽象），**不是**那个物理数值。

验证档位取 **D = 4** 的三点理由：
1. 是**整数**且够小——AD9363 采样率家族（61.44/30.72/15.36/7.68/3.84 MSPS）里，8 MSPS 档可整除到 2 MSPS；
2. `D > 1` 才能真正**压到 CIC 抽取通路**（D=1 等于旁路，60 dB 动态与溢出用例就白测了）；
3. 仿真规模可控：接收激励约 `8712 × D = 34848` 采样，比 D=15.36 这类非整数档干净得多。

> 注：接收激励由向量导出按 `f_adc` 生成（发射侧 8712 采样上采样 ×D，或直接按 `f_adc` 生成），
> TB 按 §3 拍数驱动；换档位不影响位真比对（只改激励长度与 CIC 参数）。

### 1.3 接收取样窗口与边界对齐（原 §8-6）

发射侧 `srrc_duc` 输出 **8712 = 4×2170 + 32**（full 卷积拖尾，`s4_tx_interface.md` §6.1），
接收侧稳态符号只有 **4N = 8680** 对应的 2170 符号。处理方式冻结为：

- **拖尾由接收匹配滤波窗口吸收**：`ddc_rx` 的匹配 FIR 对 8712 采样做卷积后输出更长序列，
  其中**稳态中心段**对应发射的 4N 有效段；发射的 32 拍拖尾落在接收匹配滤波的群延迟边缘，不参与判决。
- **判决窗口起点不靠猜**：以**已知前导**（同步字/前导）在接收侧的检测点对齐，
  偏移量 = 定时锁定点 + 匹配滤波群延迟补偿。该偏移在 #16 位真比对时以「与发射符号逐个同相」为唯一判据
  实测锁定，**写进向量的 `meta.json`**（与 S4 向量落 `stim_period` 同一纪律）。
- 判据：接收判决符号数 = 2170（与发射一致），比对 `errors=0`。

### 1.4 对下游的影响

- `sync_rx` 输入速率固定为 4 sps，与 `f_adc` 解耦——板级改 `f_adc` 只需改 `DECIM_RATIO`，不动下游；
- S8 全链环回：发射 8712 采样 → （×D）→ 接收激励，闭环长度可算，位真比对可判定；
- 采样率与物理时钟域（clk vs CE 门控）的取舍留实现阶段，不改拍数关系（沿用 S4 §8 的同一澄清）。

## 决策 2：同步环口径（结构冻结，参数待标定）

### 2.1 决策值

| 项 | 取值 |
|---|---|
| 载波恢复 | **二阶 Costas 环**（相位 + 频偏），直移实现，更新率 = **1/符号** |
| 定时恢复 | **早迟门（early-late gate）**，直移，更新率 = **1/符号** |
| 环路参数（Kp/Ki、环路带宽、阻尼） | **本决策只冻结"参数化 + 位宽"；数值在 #5 收敛性验证中标定后写入 `fixed_point_spec.md` 修订版** |
| 环路可观测接口 | **引出** `phase_err[15:0]` / `timing_err[15:0]`（收敛报告需要） |
| 损伤注入口径 | ±1 kHz 频偏 / 随机相偏 / ±20 ppm 符号率偏差 |
| 收敛判据 | **±1 kHz 频偏下 ≤500 符号收敛** |

### 2.2 为什么参数值不在 P0 冻结

S5 的**出口门槛**本身就写着「同步环参数冻结」——即参数是 S5 的**产物**，不是输入。P0 只冻结：
① 环路**结构**（二阶 Costas + 早迟门，不用判决反馈/ML 估计等其它结构）；
② 参数**形式**（`Kp`/`Ki` 两个系数 + 阻尼 ζ，更新率 1/符号）；
③ 参数**位宽**（系数定点宽度、误差量位宽）。
**数值**必须由 #5 的收敛测试实测标定（不同判别器增益下同一 `Kp` 收敛快慢差很多，纸上推不出可信值）。

### 2.3 参数初值的推导方法（给 #5 一个起点，非冻结值）

按二阶数字环的标准形式，归一化带宽 `B_n = B_L · T`（`T` = 符号周期 = 2 µs @ 500 ksps）：

- 阻尼 **ζ = 0.707**（临界阻尼，无过冲）；
- 系数按 `Kp = 4ζB_n / (1 + 2ζB_n + B_n²)`、`Ki = 4B_n² / (1 + 2ζB_n + B_n²)` 取初值，
  实际判别器增益并入后**必须重新标定**；
- **量级估算**：500 符号 = 1 ms 内要牵引 ±1 kHz，环路带宽须与频偏同量级，
  故 **`B_L` 取 1~5 kHz 量级**（`B_n ≈ 0.002~0.01`）；具体值 #5 扫参确定。
- 判据回填：收敛曲线（误差对符号数）+ 稳态误差，写进《同步收敛报告》。

### 2.4 与 S6 跳频的接口预留

对应 S4 §5.2 的「发射侧 NCO 相位连续」——接收侧的对应物是**环路状态在跳沿的处置**：

- 载波环：每跳中心频点突变，环路是「清零重捕」还是「保持牵引」**待 S6 冻结**；本规格只要求接口
  预留可重置 / 可保持两种语义；
- 定时环：跳频不改符号率，定时 NCO **保持不清零**；
- 预留信号：接收侧需能接收「跳沿」指示（本规格不实现，仅登记）。
（已写入 `s5_rx_interface.md` §5，此处不重复。）

## 决策 3：软判决与译码口径

### 3.1 决策值

| 项 | 取值 |
|---|---|
| 状态数 | **64**（K=7 → 2^(K−1)，与 `config.py` 的 `CONV_K=7` 一致） |
| 软判决度量位宽 | **8 bit 有符号 / 5 bit 小数**（继承 S1 `viterbi_metric_w/frac`；**不采用任务卡"5 bit"**） |
| 分支度量形式 | **绝对值型**（与 `float_chain/viterbi.py`、`fixed_viterbi_decode` 的 `abs` 模式一致） |
| 路径度量位宽 | **16 bit 有符号 / 5 bit 小数**（继承 S1 `viterbi_pm_w/pm_frac`） |
| 路径度量归一化 | **每步减全局最小值**（与浮点参考**同构**，见 3.3） |
| 回溯深度 | **96**（直移，任务卡指定） |
| 回溯存储器 | **BRAM36 × 8**（任务卡预算，实际需求见 3.4） |
| 位序 | 每符号软判决**先 I 后 Q**；译码输出 MSB-first |

### 3.2 为什么软判决位宽改回 8 bit

任务卡写「5 bit 软判决」，S1 定点规格书冻结的是 `viterbi_metric_w = 8`（3 整数 + 5 小数）。
两者冲突，本决策**以 S1 冻结值为准**，理由：

1. **位真裁判必须同源**——与 S4 §7 第 1 条（SRRC 33 抽头）同一纪律：S1 之后不再有第二套真理；
2. 「5」很可能指**小数位**（S1 的 `metric_frac = 5`），而不是总位宽；若真是 5 bit 总宽，
   软判决增益会显著劣化、BER 曲线整体抬升，与「BER 差 ≤0.5 dB」判据相冲突；
3. 若坚持 5 bit，须走 §9 变更流程**并重跑 S1 BER 基线**——代价明确，收益不明。

→ 登记为 `s5_rx_interface.md` §7 的有意偏差 #1。

### 3.3 路径度量归一化必须与浮点参考同构（位真硬约束）

16 bit PM 不归一化必然累积溢出，故每步归一化。**归一化做法必须与浮点参考一致**：

- 若 RTL 用「减状态 0 的度量」而参考用「减全局最小值」，PM 数值会**漂移**，
  回溯在低 SNR 下会分歧 → 位真比对在高 SNR 通过、低 SNR 失败，最难查；
- 故冻结为**每步减全局最小值**；RTL 的全最小值树与参考同序（同类比较树，避免并列极小值时取不同分支）。

### 3.4 回溯深度与存储预算的核对

- 回溯深度 96 = 1.5 × 64 状态，远大于经验下限（≥ 5K = 35），**有余量**，符合任务卡；
- 存储需求：`96 深度 × 64 状态 × 1 bit = 6144 bit ≈ 6 kbit`；
  **BRAM36 单块 36 kbit，8 块 = 288 kbit**——**任务卡预算远大于实际需求**（约 47 倍余量）。
  故 8 块不是约束而是宽松上限；实际块数（若按 2 bit/entry 或加 ACS 缓冲）以 #10 综合结果为准，
  **本决策不删预算**，仅登记该余量，避免后续误以为"8 块很紧张"而做无谓的位宽妥协。

## 决策 4：接收链模块边界与帧同步归属

### 4.1 决策值

| 项 | 取值 |
|---|---|
| S5 模块集 | `ddc_rx` / `sync_rx` / `viterbi_dec` + **解交织器（第 4 个）** |
| 解交织器 | **另立模块 `deinterleaver`**（逆 `blk_inter`）；S5 内可先做旁路开关，独立成一套件比对 |
| 帧同步字检测（64 bit Gold 相关） | **归 S6**（跳频层「同步字捕获」）；S5 `sync_rx` **只做符号级**（定时 + 载波） |
| 同步字长度口径 | 以 `frame_format.md` 的 **64 bit** 为准；计划书 S6 的「32 bit」为旧口径/笔误，**移交 S6 更正** |
| 软解调（LLR）归属 | 挂在 `sync_rx` **输出端**（每符号 I/Q 各 1 软比特） |

### 4.2 为什么解交织器必须显式解决

计划书 S5 只列 3 模块，但接收链是发射链的**逆**，而发射链里 `blk_inter`（交织）夹在
`conv_enc` 与 `qpsk_map` 之间（`s4_tx_interface.md` §3）。**没有解交织器，S8 全链环回必断在解交织处**：

- 若不解决，S5 判据"三模块位真全过"会**掩盖**这个断点，到 S8 才暴露，代价更大；
- 解交织器有**独立黄金参考**（`block_interleave` 的逆），可单独位真比对，切分干净；
- 塞进 `viterbi_dec` 会让"译码器"职责不纯、位真裁判难切分——故**另立**。

→ 这是对任务卡的**范围补充**，非"违反任务卡"：任务卡列 3 模块是针对"接收链算法主体"，
解交织属逆链的必备结构，登记为 §7 有意偏差 #3。

### 4.3 帧同步归属的边界

- `sync_rx` 的"同步"是**符号级**（符号定时 + 载波相位/频偏），与"帧同步字检测"是两件事；
- 帧同步字检测（滑动相关 + 恒虚警门限 + M/N 判决）在计划书里属 **S6 跳频层**；
- 故 `s5_rx_interface.md` 明确：**本规格只冻结符号级同步**，不含帧同步；
  §3 拍数账本按"已知一帧边界"计（由帧同步划定，属 S6）。
