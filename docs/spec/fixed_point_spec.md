## 1. 概述

本文档定义全链路各模块的定点化位宽、量化方式与溢出处理策略。
所有模块均采用 **有符号补码** 表示，位宽包含 1 bit 符号位。

- **量化方式**: `round`（四舍五入）
- **溢出处理**: `saturate`（饱和）

## 3. 关键节点详述

### 3.1 SRRC 输出

- **位宽**: 14 bit 有符号, 11 bit 小数
- **表示范围**: [-4.0000, 3.9995]
- **量化步长**: 4.882812e-04
- **设计说明**: SRRC 输出信号峰值约 ±2.0，留 2 bit 整数位余量，防止脉冲成形后峰值溢出。小数位 11 bit 保证足够精度。

### 3.2 Viterbi 度量

- **分支度量位宽**: 8 bit 有符号, 5 bit 小数
- **路径度量位宽**: 16 bit 有符号, 5 bit 小数
- **分支度量范围**: [-4.0000, 3.9688]
- **设计说明**: 分支度量由 QPSK 软解调输出量化而来，8 bit 足够区分各分支的度量差异。路径度量 16 bit 防止累积溢出，并采用每步减最小值的归一化策略。

### 3.3 CIC 各级（预留）

- **第 1 级**: 16 bit / 11 bit 小数, 范围 [-16.0, 16.0]
- **第 2 级**: 18 bit / 11 bit 小数, 范围 [-64.0, 64.0]
- **第 3 级**: 20 bit / 11 bit 小数, 范围 [-256.0, 256.0]
- **设计说明**: CIC 各级位宽逐级增长，匹配积分器的位宽扩展需求。具体级数和位宽根据最终插值/抽取比确定。

## 4. 验证方法

1. **定点 vs 浮点逐节点比对**: 在每个模块输出端，计算定点与浮点输出的 SNR 差异。
2. **全链路 BER 比对**: 在 Eb/N0 = 0~8 dB 范围内扫描，比较浮点与定点的 BER 曲线。
3. **出口门槛**: 定点链相对浮点 BER 损失 ≤ 0.5 dB（在目标 BER 处测量）。
