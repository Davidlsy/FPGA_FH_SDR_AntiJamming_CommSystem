## 决策 1：`srrc_duc` 输出位宽与小数位

### 1.1 决策值

| 项 | 取值 |
|---|---|
| DUC 复数混频 | 两路都保留：`I′ = I·cos − Q·sin`，`Q′ = I·sin + Q·cos` |
| 每路输出位宽 | **16 bit 有符号，11 bit 小数**（Q5.11，1 符号 + 4 整数 + 11 小数） |
| 表示范围 | [−16, 16)，量化步长 4.88e-4（与 SRRC 输出同精度） |
| 量化 / 溢出 | `round`（**half-to-even**，见 1.5）/ `saturate`（与定点规格书 §1 一致） |
| 输出总线 | `{i_out[15:0], q_out[15:0]}` = **32 bit**，高位在前（`s4_tx_interface.md` §1.6 约定） |
| SRRC 滤波器本体输出 | **不另设**，沿用定点规格书冻结的 14 bit / 11 小数（`srrc_out_w/frac`） |

### 1.2 位宽推导（从定点规格书到混频输出）

| 环节 | 位宽 | 小数 | 范围 | 来源 |
|---|---|---|---|---|
| QPSK 符号 | 12 | 10 | ±0.707（±724） | 定点规格书 `qpsk_out` |
| SRRC 系数 | 12 | 11 | [−1, 1) | 定点规格书 `srrc_coeff` |
| SRRC 输出 | 14 | 11 | [−4, 4)，峰值约 ±2 | 定点规格书 `srrc_out` |
| NCO 相位 | 16 | — | [0, 2π) | `s4_tx_interface.md` §5.2 |
| NCO LUT | 16 | 14 | [−2, 2)，实际 [−1, 1] | `s4_tx_interface.md` §5.2 |
| **DUC 混频输出** | **16** | **11** | [−16, 16)，峰值 ≤ ±8 | **本决策** |

推导：`|I′| = |I·cos − Q·sin| ≤ |I|·|cos| + |Q|·|sin| ≤ 4·1 + 4·1 = 8`（SRRC 满量程 ±4 下的最坏情况）。
表示 ±8 需要 4 bit 整数（含符号，Q4.11 = 15 bit）；§8 建议「留 2 倍余量」→ 再 +1 bit 整数 = **Q5.11 = 16 bit**，
覆盖 ±16，实际峰值 ±8 尚有 2 倍余量。

### 1.3 中间位宽口径（保证两版逐拍一致的关键）

- 乘法（I×cos、Q×sin 等）**全精度保留**（DSP48E1 累加器 48 bit 内完全容纳，14×16 与 16×16 均不溢出）；
- **只在最终输出处量化一次**：对 `I′`、`Q′` 各做 `round + saturate` 到 Q5.11；
- 两版 SRRC 与 NCO 必须**共用同一份量化系数/LUT**：SRRC 系数 12 bit（§7 偏差 #1 已定 33 抽头），
  NCO LUT 16 bit/14 小数。中间任何一处「先截断再乘」都会让 IP 版与手写版在最后一位上分叉，
  破坏「逐拍一致」判据——所以统一「全精度中间、单点量化」；
- **NCO sin/cos LUT 的镜像公式（位真一致的硬约束）**：四分之一波表存 `[0, π/2)` 的 sin，
  共 `2^14 = 16384` 项，`LUT[i] = round(sin(2πi/2^16)·2^14)`；查表按相位**高 2 bit 定象限**、
  **低 14 bit 定 `idx`**，镜像常数 `mirror = 16383 − idx`（象限 1/3 取 `LUT[mirror]` 或 `−LUT[mirror]`），
  `cos(p) = sin(p + 2^14)`。**RTL 必须逐项复刻这套公式（含 `16383` 这个镜像常数）**，否则端点 π/2
  处的 ±1 LSB 差异会让 IP 版、手写版、模型三方在最后一位分叉。该公式带来 ≤1.57 LSB 的端点固有误差
  （π/2 被离散到 `16383` 而非精确 `16384`），是标准四分之一波 DDS 行为，SFDR 判据 −50 dBc 下无碍。
  黄金裁判已按此实现并通过 18 项自检（`sim/golden_ref/sim/check_duc.py`）。

### 1.4 对下游的影响

- `qpsk_map` 输出 24 bit、`srrc_duc` 输出 32 bit，两者**不跨模块比较**（各对各自的黄金向量）；
- 32 bit 输出是 S5 接收链 `ddc_rx` 的输入口径（后续接收链位宽以其为准，届时再冻）；
- AD9363 物理接口位宽（12 bit CMOS）**不在此决策内**——那是板级 BV-03 / 顶层集成的截断点，
  仿真域结论不引用物理接口位宽。

### 1.5 两个位真一致的口径（本决策新增，均来自实测裁判）

**① 输出拍数 = 4N + 32（full 卷积），不是 4N。**

`fixed_pulse_shape` 用 `np.convolve`（full 模式）做 33 抽头滤波，输出长度 `4N + 32`；实测
2170 符号 → **8712 采样**（最后 3 个采样值为 0，倒数第 4 个仍是滤波器尾部非零）。
接口规格 §3 写的 `8680（= 4N）` 是**简化口径错误**，P3 合入时须修正为 `4N + 32`（对 2170 符号 = 8712）。
RTL 因此要在符号流结束后再输出 **32 拍拖尾**（`NUM_TAPS − 1`），位真比对以 8712 拍为准。

**② 舍入是 `round half-to-even`，不是 half-up。**

`golden_ref.quantizer` 用 `np.round`（half-to-even），而 SRRC 量化到 14 bit 时实测 **66 + 78 个采样
恰逢 `.5`**（I/Q 两路），DUC 混频同理——若 RTL 用常见的「加 0.5 截断」（half-up），这些拍会与裁判
差 1 LSB，破坏逐拍一致。RTL 必须复刻 half-to-even，进位条件（丢弃低 `DROP` 位）：

```
round_bit = v[DROP-1];  sticky = |v[DROP-2:0];  lsb = v[DROP]
carry     = round_bit && (sticky || lsb)
result    = (v + (carry << DROP)) >> DROP      // 算术右移
```

已用 ±2.5 / ±3.5 / ±1.5 等补码样例逐点验证该公式与 `np.round` 一致。

## 决策 2：目标时钟与采样率

### 2.1 决策值

| 项 | 取值 |
|---|---|
| 起步采样率 `fs` | **2 MSPS**（AD9363 首版起点，用户已答 40 MHz 晶振 + 2 MSPS） |
| 符号率 `Rs` | **500 ksps**（= fs / `UPSAMPLE_FACTOR` = 2e6 / 4） |
| 拍数关系 | 符号 : 采样 = **1 : 4**（已冻结，不因频率改变） |
| RTL 时钟抽象 | **采样节拍**：每采样节拍输出 1 个采样点，符号每 4 节拍 1 个 |

### 2.2 关键澄清：拍数关系与物理时钟域解耦

位真比对**只认拍数（1:4）与 valid 对齐，不认绝对频率**（`s4_tx_interface.md` §1.3）。
§8.2 原话「与顶层时钟方案一起定」里，真正需要冻结的只有**采样率数值**（用于 SFDR 频率标定
与顶层 MMCM 规划）；RTL 的物理时钟域是「采样时钟（clk = fs）」还是「基带时钟 + 时钟使能（CE）
门控输出 2 MSPS 有效采样」，属 P3 综合/实现时的取舍，**不改拍数关系、不影响位真比对**。

本决策冻结「采样节拍」这个逻辑抽象：TB 里每个 `clk` 沿 = 1 个采样节拍，符号以 `STIM_PERIOD=4`
节奏进（P0 已落地的激励节奏能力，直接复用）。物理时钟域留 P3 实现时定，不阻塞 P3 开工。

### 2.3 NCO 固定频点（S4 阶段）

S4 只用固定频点（§5.2）。SFDR 单音测试需要一个落在 SRRC 通带内的相干频点：

- **建议 `f0 = fs / 8`**（`freq_word = 8192`，16 bit 相位累加器可精确表示，无相位截断杂散）；
- `f0 = 0.125·fs < 0.16875·fs`（SRRC 单边带宽 `(1+α)/(2·sps) = 1.35/8`），落在带内；
- 相干采样 N = 16384 点时 `f0` 恰好落在 bin 2048，整数 bin 无频谱泄漏，SFDR 测量最干净。
- 该值属**建议值**，评审可换（仅影响 SFDR 频谱标定，不影响位真比对）。

### 2.4 对下游的影响

- 采样率提升（2 → 20 MSPS，吞吐达标）只改频率标定与顶层时钟，**不改 1:4 拍数关系**；
- `srrc_duc` 的接口（valid 流 + 32 bit 数据 + `freq_word/freq_valid`）与采样率数值无关，
  未来提速无需改接口。

## 决策 3：SFDR 分析方法

### 3.1 决策值

| 项 | 取值 |
|---|---|
| SFDR 测量对象 | NCO/DUC 混频输出（**纯单音 → DUC**，跳过 SRRC 多相） |
| DAC 模型 | **理想 DAC**：采样点直接进 FFT，不建模 INL/DNL/孔径抖动/镜像（模拟非理想属 BV-03） |
| 判据 | **SFDR ≤ −50 dBc**（任务卡 S4，只作用于 NCO/DUC 量化杂散） |
| 激励 | SFDR 判据：纯单音（Q3.11 DC 复指数）；SRRC 频谱纯度报告：①恒定符号单音 ②满量程随机 |
| FFT | 单音用**矩形窗 + 相干采样**；随机用**加窗（Blackman-Harris）** |

### 3.2 「理想 DAC 模型」的定义边界

SFDR 在本决策里是**数字域**指标：把 16 bit 采样点当作理想 DAC 的量化输出，FFT 直接作用于采样
序列。测到的是量化、相位累加器（16 bit 不截断）、LUT（16 bit/14 小数）、有限精度运算引入的杂散——
以上均为 **NCO/DUC 段**；SRRC 滤波器的多相差异与阻带抑制属滤波器设计指标，不在此列（见 §3.3 ②③），
**不含** AD9363 模拟链路（噪声系数、IQ 不平衡、本振泄漏、非线性）——那些按任务卡口径移交 BV-03，
本决策不得引用为「真实发射频谱」。

### 3.3 激励与测量口径

**① 纯单音 → DUC 混频（SFDR 判据，跳过 SRRC）**
- 跳过 SRRC 多相，直接以 Q3.11 量化的 DC 复指数（I=Q=+0.707）进 DUC 混频，上变频到 `f0 = fs/8`；
- 测到的是 NCO LUT（16 bit/14 小数）+ 复数混频（16 bit）量化引入的杂散——这才是 SFDR 的本义（§3.2）；
- **相干采样**：N = 16384 点，`f0` 落整数 bin（bin 2048），矩形窗（无泄漏最干净）；
- SFDR = 主音功率 − 最高杂散功率（排除主瓣 ±5 bin 近邻）。

**② 恒定符号单音 → SRRC → DUC（SRRC 多相一致性，报告项）**
- 恒定符号（I=Q=+724）经 SRRC 多相分解，输出带周期 4 扰动（4 个多相子滤波器 DC 增益天然不等）
  → 混频后产生 3f0/7f0 谐波；
- 实测 ≈ **−44.68 dBc**，是 SRRC 多相分解固有（浮点系数亦 ≈ −45.8 dBc），**与系数位宽无关**；
- 作为滤波器设计指标如实登记，不套 −50 dBc 判据。

**③ 满量程随机 → SRRC → DUC（SRRC 阻带抑制，报告项）**
- ±724 随机 QPSK → SRRC + NCO，输出为带内调制信号；
- 加窗（Blackman-Harris）压低频谱泄漏，否则窗旁瓣会污染带外测量；
- 带外最高杂散相对带内峰值功率密度，实测 ≈ **−32.51 dBc**，是 33 抽头有限长截断的阻带抑制固有；
- 作为滤波器设计指标如实登记，不套 −50 dBc 判据。

### 3.4 判据可达性与黄金模型对照

- **口径修正（2026-10-07 实测，原稿「≥45 dB 余量」估计有误）**：原稿只算了 NCO LUT(16 bit) +
  混频(16 bit) 的量化（≈ −96 dBc），遗漏 SRRC 链路两个固有杂散源——多相 DC 增益差异（恒定符号单音
  −44.68 dBc）与 33 抽头有限长阻带（随机带外 −32.51 dBc）。故「SFDR ≤ −50 dBc」在
  「恒定符号→SRRC→DUC」口径下**不可达**；SFDR 判据改为只测 NCO/DUC 量化杂散（纯单音口径，实测
  **−85.45 dBc** 达标，最高杂散来自 NCO LUT 镜像端点误差的谐波），SRRC 频谱纯度降为报告项（§3.3 ②③）。
- RTL 输出与 `golden_ref` 定点 DUC 模型**逐拍一致**后，SFDR 用同一份 FFT 脚本跑两边，曲线应重叠——
  SFDR 判据值以逐拍一致为前提，二选一即可，无需分别读数；
- 建议 P4 采数时顺手记录「FIR IP 版 vs 手写版」的 SFDR 是否也一致（两版逐拍一致，理应一致），
  作为对比实验的第三栏佐证。
