项目名称 基于高云 FPGA 的无线通信系统设计
开发平台 Tang Mega 60K（GW5AT-LV60PG484A）
射频前端 外接 AD9361 类 SDR 收发模块
开发工具 高云云源 IDE + ModelSim + MATLAB
方案版本 V1.0

概述

本方案将设计报告中的系统设计拆解为 8 个实施阶段、40 余个可执行步骤，覆盖从环境搭建、算法建模、FPGA 编码、系统集成、射频接入到测试优化的完整流程。每一步均给出目标、具体操作、关键参数、验证标准与产出物，供团队按序推进。

阶段一：环境搭建与工具准备（第 1 周）

步骤 1.1 安装高云云源 IDE

  • 目标：搭建 FPGA 综合、布局布线、下载调试环境。
  • 操作：
    1. 前往高云半导体官网下载 Gowin 云源 IDE，商业版 ≥ V1.9.10.03 或 教育版 ≥ V1.9.11.03（Tang Mega 60K 需该版本以上才支持 GW5AT-LV60）。
    2. 安装时勾选 Programmer（编程器）；推荐单独安装 V1.9.12 SP1 云源编程器。
    3. 申请 License（商业版）或使用 Sipeed 提供的在线 Float Lic 服务。
  • 验证：新建工程，在器件列表中找到 GW5AT-LV60PG484A，封装选择 PBG484A、Device Version 选 B。
  • 产出：可正常创建工程的 IDE 环境。

步骤 1.2 安装仿真工具 ModelSim

  • 目标：搭建 RTL 功能仿真环境。
  • 操作：安装 ModelSim（或高云 IDE 内嵌仿真器），将仿真库路径加入工程。
  • 验证：运行一个计数器例程仿真，能查看波形。
  • 产出：可用的仿真环境。

步骤 1.3 安装 MATLAB

  • 目标：搭建浮点参考模型与滤波器系数生成环境。
  • 操作：安装 MATLAB（含 Communications Toolbox、DSP System Toolbox、Filter Designer）。
  • 验证：运行 rcosdesign、convenc、vitdec 等函数确认工具箱可用。
  • 产出：可用的算法验证环境。

步骤 1.4 硬件清单核对与连接

  • 目标：确认硬件齐备并正确连接。
  • 操作：
    1. 核对清单：Tang Mega 60K 板卡 ×1、AD9361 射频模块 ×1、12V DC 电源、USB 数据线、天线、杜邦线/排线、衰减器（测试用）、SD 卡。
    2. 将射频模块通过 PMOD/40P 排针连接 SPI 与 I/Q 接口，天线接入射频模块。
    3. 用 USB 线连接板卡 DEBUG-USB2 接口至 PC，接入 12V DC 电源。
  • 验证：按 PWR 键 2 秒开机，Programmer 能识别设备（无 "No USB Cable Connection" 提示）。
  • 产出：可上电调试的硬件平台。

阶段二：MATLAB 浮点参考模型（第 2-3 周）

步骤 2.1 搭建 QPSK 收发浮点模型

  • 目标：建立端到端基带链路浮点模型，作为 FPGA 定点实现的"黄金参考"。
  • 操作：
    1. 生成随机比特流 → QPSK 格雷映射 → RRC 成型（rcosdesign(0.35, 8, 4)，每符号 4 采样）→ 加噪声 → 匹配滤波 → 下采样 → 判决 → 统计 BER。
    2. 绘制星座图、眼图、BER-SNR 曲线。
  • 验证：无噪声时 BER=0；有噪声时 BER 曲线与理论 QPSK 曲线（berawgn）吻合。
  • 产出：matlab/qpsk_link.m，BER 理论基线。

步骤 2.2 卷积码编解码模型

  • 目标：验证 (2,1,7) 卷积码 + Viterbi 软判决的正确性。
  • 操作：
    1. 用 poly2trellis(7, [171 133]) 建网格，convenc 编码，vitdec(...,'soft',3) 软判决译码。
    2. 对比硬判决与软判决的 BER 增益。
  • 验证：软判决较硬判决约 2 dB 增益，编码整体约 5 dB 增益。
  • 产出：matlab/conv_code.m，编码/译码参考模型。

步骤 2.3 同步算法模型

  • 目标：验证帧同步、频偏估计、Costas 环、Gardner 定时的算法有效性。
  • 操作：
    1. 帧同步：用 32 bit PN 序列做滑动相关，验证相关峰检测。
    2. 载波同步：仿真修正 Costas 环，施加频偏/相偏，验证锁定。
    3. 定时同步：仿真 Gardner 算法，施加时钟偏差（±100 ppm），验证收敛。
  • 验证：在 ±5% 符号率频偏、±100 ppm 时钟偏差下均能锁定。
  • 产出：matlab/sync_model.m，同步参数（环路带宽、阻尼系数）设计值。

步骤 2.4 生成定点化参考数据与滤波器系数

  • 目标：生成 FPGA 实现所需的定点系数与测试向量。
  • 操作：
    1. 生成 40 阶 RRC 滤波器系数并定点化为 16 bit 有符号整数，导出为 .coe/.mem 文件。
    2. 生成一组定点化测试激励（I/Q 数据、编码后比特）及对应的期望输出，供 FPGA 仿真比对。
    3. 确定各模块定点位宽（数据通路 18 bit、相位累加 16 bit 等）。
  • 验证：定点模型与浮点模型误码率差异 ≤ 0.2 dB。
  • 产出：matlab/coeff.mem、matlab/test_vectors.txt、定点化方案文档。

阶段三：发送链路 FPGA 实现（第 4-5 周）

统一约定：时钟 clk，复位 rst_n，数据有效 din_valid/dout_valid。

步骤 3.1 信源模块（PN 序列发生器）

  • 目标：产生测试数据比特流。
  • 操作：实现 LFSR 伪随机序列发生器（如 9 级 m 序列，本原多项式 x⁹+x⁴+1），输出 1 bit/时钟的比特流；预留 SD 卡/网口数据接口。
  • 关键信号：pn_out[0:0]、pn_valid。
  • 验证：仿真输出序列与 MATLAB 生成的 PN 序列一致。
  • 产出：rtl/tx/pn_gen.v。

步骤 3.2 组帧 + CRC-16

  • 目标：将数据封装为固定帧结构，附加 CRC 校验。
  • 操作：实现帧头（前导 + UW + 帧头）插入模块与 CRC-16 生成器（多项式 0x8005），按 4.7 节帧格式组帧。
  • 关键信号：frame_out、frame_valid、frame_start。
  • 验证：输出帧格式与 MATLAB 组帧结果一致，CRC 计算正确。
  • 产出：rtl/tx/framer.v、rtl/tx/crc16.v。

步骤 3.3 卷积码编码器

  • 目标：实现 (2,1,7) 卷积码编码。
  • 操作：6 级移位寄存器 + 2 路模 2 加，生成多项式 g₁=171、g₂=133；每帧结束插入 6 个尾比特归零。
  • 关键信号：din[0:0]、dout[1:0]。
  • 验证：编码输出与 MATLAB convenc 结果逐比特一致。
  • 产出：rtl/codec/conv_enc.v。

步骤 3.4 块交织器

  • 目标：实现 8×8 块交织，打散突发错误。
  • 操作：用双端口 Block SRAM 按行写入、按列读出，实现交织与解交织共用模块（读写方向可切换）。
  • 验证：交织-解交织级联后数据完全还原。
  • 产出：rtl/codec/interleaver.v。

步骤 3.5 QPSK 星座映射

  • 目标：将比特映射为 I/Q 符号。
  • 操作：实现格雷映射查找表（00→(+1,+1)、01→(-1,+1)、11→(-1,-1)、10→(+1,-1)，归一化 1/√2），输出 18 bit 定点 I/Q。
  • 验证：映射表与设计报告 4.4 节一致。
  • 产出：rtl/tx/qpsk_map.v。

步骤 3.6 RRC 成型滤波与插值

  • 目标：实现根升余弦滤波与符号到采样率的插值。
  • 操作：采用多相 FIR 结构，40 阶、每符号 4 采样，系数从 coeff.mem 读入 ROM；乘法器用 18×18 硬核。
  • 验证：输出波形与 MATLAB 成型结果比对，归一化误差 < 1%。
  • 产出：rtl/tx/rrc_tx.v、rtl/tx/coeff_rom.v。

步骤 3.7 发送链路模块级仿真

  • 目标：验证发送链路各模块级联正确性。
  • 操作：编写 testbench，将各模块串联，注入测试数据，导出 I/Q 波形与 MATLAB 比对。
  • 验证：输出 I/Q 与 MATLAB 参考一致。
  • 产出：sim/tx_tb.v 及仿真报告。

阶段四：接收链路 FPGA 实现（第 5-6 周）

步骤 4.1 匹配滤波器

  • 目标：实现接收端 RRC 匹配滤波。
  • 操作：复用发送端 RRC 系数，实现接收匹配滤波（结构同 3.6）。
  • 验证：匹配滤波输出与 MATLAB 一致。
  • 产出：rtl/rx/rrc_rx.v。

步骤 4.2 帧同步与频偏估计

  • 目标：检测帧到达并估计载波频偏。
  • 操作：
    1. 本地 UW 与接收序列滑动相关，相关峰过门限判定帧同步。
    2. 利用前导重复结构做差分相关，估计频偏，输出 NCO 校正量。
  • 验证：在指定频偏下能正确检测帧同步并估计频偏，误差 < 1%。
  • 产出：rtl/sync/frame_sync.v、rtl/sync/freq_est.v。

步骤 4.3 Costas 环载波同步

  • 目标：恢复载波相位，消除残留频偏/相偏。
  • 操作：实现鉴相器 sign(I)·Q − sign(Q)·I + PI 环路滤波器 + NCO（CORDIC），完成相位跟踪。
  • 验证：施加相偏后能收敛锁定，星座点旋转消除。
  • 产出：rtl/sync/costas_loop.v、rtl/sync/nco.v。

步骤 4.4 Gardner 定时同步

  • 目标：恢复最佳采样时刻。
  • 操作：实现 Gardner 定时误差检测 + PI 环路滤波器 + Farrow 插值滤波器，每符号 2 采样点误差计算。
  • 验证：±100 ppm 时钟偏差下眼图张开、判决正确。
  • 产出：rtl/sync/gardner.v、rtl/sync/farrow.v。

步骤 4.5 判决、解交织与 Viterbi 译码

  • 目标：完成符号判决与信道译码。
  • 操作：
    1. 星座判决：根据 I/Q 符号位恢复双比特，并生成 4 bit 软值。
    2. 解交织（复用交织模块反向）。
    3. Viterbi 译码：实现 BMC/ACS/TB，64 状态、回溯深度 40。
  • 验证：译码输出与 MATLAB vitdec 一致。
  • 产出：rtl/rx/qpsk_demap.v、rtl/codec/viterbi.v。

步骤 4.6 解帧与 CRC 校验

  • 目标：恢复原始数据并检测帧差错。
  • 操作：实现解帧器（提取数据载荷）+ CRC-16 校验，输出数据与 crc_ok 标志。
  • 验证：无差错时 crc_ok=1 且数据还原；注入错误时检出。
  • 产出：rtl/rx/deframer.v。

步骤 4.7 接收链路模块级仿真

  • 目标：验证接收链路级联正确性。
  • 操作：用发送链路输出的 I/Q（加噪声/频偏/相偏）作为激励，跑通接收链路。
  • 验证：BER 与 MATLAB 参考一致。
  • 产出：sim/rx_tb.v 及仿真报告。

阶段五：系统集成与数字回环（第 7 周）

步骤 5.1 顶层例化与时钟管理

  • 目标：整合收发链路，建立时钟树。
  • 操作：
    1. 例化 tx_top、rx_top、同步模块、状态机；
    2. 配置 PLL：生成射频参考时钟、符号时钟（5 MHz）、系统时钟（100~200 MHz）；
    3. 时钟域间用异步 FIFO 做 CDC。
  • 验证：综合通过，时序无违例。
  • 产出：rtl/top/sdr_top.v、PLL IP 配置。

步骤 5.2 LVDS/并行 I/Q 接口

  • 目标：实现与射频前端的数据接口。
  • 操作：实现 LVDS 收发接口或并行 I/Q 接口，完成 FPGA 基带数据与射频模块 I/Q 数据的对接。
  • 验证：接口回环测试数据无误。
  • 产出：rtl/top/lvds_if.v。

步骤 5.3 数字回环联调

  • 目标：在不接射频的情况下验证完整基带链路。
  • 操作：将发送链路 I/Q 直接回环到接收链路（LVDS 发→收数字回环），统计 BER。
  • 验证：数字回环下 BER=0（或接近 0），全链路数据还原。
  • 产出：数字回环测试报告。

阶段六：射频前端接入（第 8 周）

步骤 6.1 AD9361 硬件连接与初始化

  • 目标：完成射频模块电气连接与上电初始化。
  • 操作：
    1. 核对 SPI（CS/SCLK/MOSI/MISO）、I/Q、参考时钟、电源连线；
    2. 提供参考时钟（MS5351 或 FPGA PLL）；
    3. 上电，检查射频模块工作正常。
  • 验证：射频模块初始化完成，寄存器可读写。
  • 产出：接线记录、初始化状态。

步骤 6.2 SPI 配置驱动

  • 目标：实现 AD9361 寄存器配置。
  • 操作：
    1. 实现 SPI 主机（Mode 0，时钟 ≤ 25 MHz）；
    2. 编写寄存器配置序列：载波频率（2400~2483.5 MHz）、发射功率、接收增益、滤波器带宽、采样率；
    3. 封装为 rf_cfg 模块，支持串口下发动态配置。
  • 验证：配置后射频模块按设定频率/功率工作（频谱仪观测）。
  • 产出：rtl/top/spi_master.v、rtl/top/rf_cfg.v、配置表文档。

步骤 6.3 射频回环联调

  • 目标：打通射频收发链路。
  • 操作：天线自环或衰减器直连，发送端→射频→接收端完整链路，统计 BER、观测星座图/频谱。
  • 验证：射频回环下 BER ≤ 1×10⁻⁵（20 dB 信噪比），占用带宽约 6.75 MHz。
  • 产出：射频回环测试数据。

阶段七：参数配置与性能优化（第 9 周）

步骤 7.1 频率/功率/增益配置与扫描

  • 目标：实现并验证射频参数可配置。
  • 操作：通过串口/网口下发命令，扫描不同频率、功率、增益，记录链路状态。
  • 验证：参数配置即时生效，链路保持稳定。
  • 产出：参数配置接口与测试记录。

步骤 7.2 BER 测试与误码率优化

  • 目标：绘制 BER-SNR 曲线并优化误码率。
  • 操作：
    1. 用衰减器改变信噪比，逐点统计 BER，绘制曲线；
    2. 优化环路滤波器参数、AGC 阈值、量化位宽；
    3. 对比编码前后 BER，验证编码增益。
  • 验证：BER 曲线与理论值接近，达到指标。
  • 产出：BER-SNR 曲线与优化报告。

步骤 7.3 传输距离测试

  • 目标：验证并优化无失真传输距离。
  • 操作：加衰减器等效远距离，或实测拉开天线距离，记录最远无失真传输距离；必要时切换 BPSK 模式提升链路余量。
  • 验证：记录无失真传输最远距离、传输时延（≤ 5 ms）。
  • 产出：距离与时延测试报告。
