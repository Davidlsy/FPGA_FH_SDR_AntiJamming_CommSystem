# S2 验证基础设施 · 信道模型库

计划书 §S2 第二件交付物。没有板卡就没有真实的电磁环境，S5/S6/S7/S8 在仿真域里
需要一条**可控、可复现、口径与 S1 基线一致**的信道。本库提供这条信道，并附带
一套**解析判据**的自核验（不另写一套 numpy 参考模型——两套「真理」是这类验证
最容易翻车的地方）。

## 1. 组成

| 文件 | 作用 |
|---|---|
| `ch_pkg.sv` | 共用原语：定点量化（半值取偶 + 饱和，与 `golden_ref.quantizer` 对齐）、xorshift32、Box-Muller 高斯 |
| `ch_awgn.sv` | 加性高斯白噪声，噪声口径与 `golden_ref` 的 `add_awgn` 同源 |
| `ch_cfo.sv` | 载波频偏，相位连续复数旋转（与 S6 `nco_hop` 同构） |
| `ch_sfo.sv` | 采样率偏差，采样相位线性漂移 + 滑码计数 |
| `ch_multipath.sv` | 多径：指数 PDP + 首径莱斯/瑞利，准静态可重抽 |
| `ch_top.sv` | 信道链：多径 → SFO → CFO → AWGN，四级各自可旁路 |
| `tb_channel_stats.sv` | 七场景核验 TB，导出样本到 `dump/` |
| `check_channel_stats.py` | 解析判据检查器，出一张 29 项核验表 |
| `run_channel_check.ps1` / `.bat` | 一键：编译 → 跑七场景 → 核验 |
| `dump/` | 场景样本与配置（`*.log`，已被 gitignore，可随时重跑重建） |

## 2. 接口

```systemverilog
ch_top #(.W(14), .FRAC(11), .EB_N0_DB(4.0), .NTAPS(4), .PDP_DECAY_DB(3.0)) u_ch (
    .clk, .rst_n,
    .in_valid, .in_i, .in_q,          // 定点 I/Q（补码）
    .cfg_mp_en, .cfg_sfo_en, .cfg_cfo_en, .cfg_awgn_en,   // 四级旁路开关
    .cfg_sfo_ppm, .cfg_cfo_ftw, .cfg_mp_k_db_x10, .cfg_mp_reseed,
    .out_valid, .out_i, .out_q, .slip_cnt
);
```

- **所有 `cfg_*_en = 0` 时整链逐位透明**（只多 4 拍流水线延迟），可作为恒等自检；
- 数据通路按 `*_valid` 逐拍握手，**对接时按各拍 valid 对齐，不要按绝对时间对齐**
  （SFO 开启时会多 1 拍插值延迟，与 `sim/framework` 的逐拍比对口径一致）；
- 输出量化到规格书「AWGN 信道输出 / 同步模块输出」的 **14 bit / 11 小数**，
  round-half-even + saturate，与 `docs/spec/fixed_point_spec.md` 一致。

## 3. 口径（为什么这么做）

**AWGN 必须与 S1 同源。** 噪声按
`eb = Es/bit_rate`、`n0 = eb/10^(EbN0/10)`、**每维方差 = n0/2** 生成，与
`golden_ref/float_chain/awgn.py` 的 `add_awgn` 完全一致。若这里换了口径，S8 环回的
BER 曲线就对不上 S1 基线，而这种差异极难在整链里定位。检查器不是「按同一个公式
重写一遍」，而是**直接调用 `add_awgn` 现算期望 σ** 与模型输出比对。

**CFO 用自研相位累加器且不清零。** 相位连续（只累加 FTW）与 S6 `nco_hop` 同构，
这样 S6 做相位连续性验证时，信道侧引入的频偏与 NCO 的清零行为是可分辨的独立效应。
归一化频偏 = `FTW / 2^32` cycle/sample；要按 Hz 给就取
`FTW = round(f_cfo/fs × 2^32)`。

**SFO 建的是「采样相位漂移」，不是「按绝对时间重采样」。** 后者输出样本的输入时间
坐标会相对输入流无界漂移（`t_m = m·ratio` 与输入计数之差随 m 线性增长），任何有限长
历史缓冲都会在几千拍后耗尽、模型自己停摆。而对接收链真正可观测的 SFO 效应就是
**采样相位随时间漂移**：

```
y[m] = (1-μ_m)·x[m] + μ_m·x[m+1],   μ_m = frac(m·δ),  δ = ppm × 1e-6
```

每收一个输入样本推进一次 μ，μ 越过 1 时绕回（滑掉一个采样点，`slip_cnt` 计数）。
μ 有界、每输入一拍出一拍、`y` 落在 `[m, m+1)` 不会溢出。δ = 0 时恒等。

**多径的 K 定义：首径的视距功率 / 首径散射功率。** 抽头功率按指数 PDP 分配并归一化
（Σp_k = 1），首径拆成视距 + 散射，其余抽头为纯瑞利。于是
**E|h_k|² = p_k 对所有抽头成立、Σ E|h_k|² = 1、由首径样本估出的 K 就等于配置值**。

> 踩过的坑：把 `(K+1)` 摊到**所有**抽头（而不是只摊首径）会让除首径外的抽头白掉
> `(K+1)` 倍功率，总功率不再为 1——K = 6 dB 时实测只剩 0.628。

**FIR 约定为标准因果形式** `y[m] = Σ h[k]·x[m-k]`，抽头 0 乘**当前**输入，冲激响应
与系数逐拍一一对应。

## 4. 核验（29 项解析判据，本机全部通过）

```powershell
.\run_channel_check.ps1        # 或双击 run_channel_check.bat
```

七个场景顺序跑，每个场景前复位一次（延迟线、插值历史、相位累加器、噪声种子归零），
只开一级效应：

| 场景 | 核验内容 | 实测 |
|---|---|---|
| `identity` | 全旁路逐位透明 | 2048 拍 0 失配 |
| `awgn` | 每维均值、σ 对齐 `golden_ref` 现算值、自相关白性、PSD 平坦度、I/Q 独立、无饱和 | σ 0.44568 vs 0.44615；自相关 max 0.0092；PSD 标准差 0.547 dB |
| `cfo` | 相位斜率 = 2π·FTW/2³²、幅度不变、逐拍相位增量恒定 | 斜率相对误差 3.4e-10；max\|A−1\| = 2.1e-4 |
| `sfo` | μ_m 精确等于 frac(m·δ)、输出 = quant(m+μ)、滑码计数 | μ 偏差 < 1e-9；滑码 20 = ⌊4096×5e-3⌋ |
| `mp_impulse` | 冲激响应 = 抽头系数；抽头外为 0 | 最大误差 **0.000 码** |
| `mp_rayleigh` | 各抽头功率 = 指数 PDP、Σ\|h\|² = 1、幅度比 = π/4、K→0 | PDP 1.14%；功率 0.9946；比值 0.7881 vs 0.7854 |
| `mp_rician` | 同上，并由统计估出 K | 功率 1.0005；K 估计 **6.060 dB** vs 配置 6.000 dB |

明细表落 `data/s2_channel_stats/channel_stats_table.csv`（与 S1 的
`data/s1_ber_baseline/snr_loss_table.csv` 同一证据约定）。

检查器输出一行 ASCII 机器可读结果，脚本/CI 只认它：

```
[CH-RESULT] check=awgn_std_i status=PASS measured=0.445683 expected=0.446154 tol=rel 2%
[CHANNEL STATS] PASS (29 项全部达预期)
```

## 5. 怎么接到 S8 环回

TX 链输出（14/11 I/Q）→ `ch_top` → RX 链输入。三段各自按 valid 逐拍握手：

- 先全旁路跑一遍，RX 输出应与**不加信道**的结果逐位一致（验证接线与透明性）；
- 再逐级开效应，每开一级只应看到该级的预期变化（CFO → 星座旋转；SFO → 采样相位
  漂移；多径 → 幅度/相位起伏；AWGN → BER 随 Eb/N0 抬升）；
- 时变多径用 `cfg_mp_reseed` 在 burst 边界重抽即可先跑通。

## 6. 已知边界（别把这里的能力想多）

| 边界 | 说明 | 影响 |
|---|---|---|
| **时变衰落未建模** | 抽头为准静态，`cfg_mp_reseed` 在 burst 边界重抽；没有多普勒谱成形 | 需要快衰落场景时得另加成形滤波器；BER 曲线按准静态给的与快衰落不同 |
| **SFO 是相位漂移模型** | 见 §3；不是绝对的采样率变换 | 适合验证定时恢复的跟踪能力，不适合评估长时间样本计数漂移 |
| **AWGN 的 Es 由参数给定** | 不在线估计输入功率 | 换调制/成形系数时要同步改 `ES` 与 `BIT_RATE`（口径同 `add_awgn`） |
| **无量化误差补偿** | 输出按 14/11 量化，与 S1 一致 | 输出已含量化噪声（σ_q ≈ LSB/√12），统计核验的容差按此设定 |
| **TB 用层次引用取内部量** | `tb_channel_stats` 读 `u_ch.u_sfo.mu_used`、`u_ch.u_mp.h_i` 等 | 便于核验且不污染模型端口；改动 `ch_top` 内部信号名要同步改 TB |

## 7. 踩过的坑（改这个库之前先看）

| 现象 | 原因 | 对策 |
|---|---|---|
| `xelab` 报 `variable is driven by invalid combination of procedural drivers` | 同一变量被 `initial` 与 `always_ff` 两个进程驱动（`seed_q`） | 种子与抽头生成统一收进同一个进程 |
| dump 全是 0 字节空文件 | 开/关激励写成两个任务背靠背调用，`stim_active` 在同一时间步内被置 1 又清 0，驱动器一个时钟沿都看不到 | 开激励与关激励必须在同一任务里隔着时钟沿做 |
| 冲激响应偏差上千码 | 相位之间没复位，延迟线里还留着上一场景的斜坡样本 | 每个场景前复位一次 |
| `(输出值, μ)` 差两拍 | 顶层输出要经 CFO、AWGN 两级寄存才到 TB，而 μ 每拍被覆盖 | 该场景直接从 SFO 子模块出口取数（层次引用） |
| 噪声 σ 差了 2048 倍 | dump 是定点码值，σ 定义在实数域 | 核验前除以 `2^FRAC` |
| 纯瑞利被判成莱斯分支 | 判据阈值写成 `≤ -100 dB`，而 TB 用 −99 dB 表示纯瑞利 | 阈值统一为 −20 dB（写入 `PURE_RAYLEIGH_MAX_DB`） |
| 力量总功率只有 0.628 | `(K+1)` 摊到了所有抽头 | 只对首径拆 K，其余抽头纯瑞利 |
